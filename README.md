## Версия 4.0.39 — финальный аудит «Задачи»

Проверена логика и оформление страницы «Задачи».

Исправлено:
- убран свайп по строкам задач: вертикальная прокрутка больше не конфликтует с горизонтальным жестом;
- выбранный фильтр автоматически остаётся видимым в горизонтальной ленте;
- поиск расширен: учитывает место/суд, правило и статью процессуального срока;
- пустой экран при активном фильтре теперь объясняет, что записей нет именно по выбранным условиям;
- стрелка справа у записи стала реальной кнопкой открытия, а не декоративным элементом;
- подтверждение удаления различает задачу, встречу, срок и заседание.
