# Ежедневник адвоката 5.0.114

## 5.0.114 — вкладка «Напоминания» пересобрана нативно

- Полностью убран подход с использованием готового скриншота вкладки как подложки.
- Экран собран заново из HTML/CSS и отдельных утверждённых assets: мраморный фон, верхний медальон, две иконки карточек и нижние весы.
- ON/OFF меняет только текст, статусную плашку и подпись кнопки; геометрия экрана остаётся одинаковой.
- Карточки имеют фиксированную геометрию, поэтому текст больше не смещает соседние элементы.
- Шторка рассчитана на размещение без вертикальной прокрутки на iPhone.
- Обновлены версия и кеш: build 5114.
