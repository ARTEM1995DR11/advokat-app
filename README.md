# Ежедневник адвоката — версия 3.1.87

В этой версии страница конкретного дела приведена к премиальному виду по утверждённому макету.

Ключевые изменения:
- светлая и тёмная тема карточки дела приведены к единому премиальному стилю;
- убран блок с днями участия из основной карточки дела;
- блоки действий, задачи и журнал дела переработаны визуально.

Версия 3.1.86 — удалена категория «Исполнительное / ФССП» со страницы «Дела».

Что изменено:
- из фильтрации и карточек страницы «Дела» убран тип «Исполнительное»;
- из формы создания/редактирования дела убран выбор «Исполнительное»;
- для старых записей с типом enforcement отображение будет идти как «Иное», без отдельной категории ФССП.
