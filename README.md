# Ежедневник адвоката — iPhone Offline 3.1 Business

Автономное PWA-приложение для личной адвокатской практики. После первой установки с HTTPS-адреса
работает с экрана iPhone без постоянного подключения к интернету. На GitHub/хостинге лежат только
файлы программы — рабочие данные доверителей туда не отправляются.

## Основные возможности

- деловой интерфейс: «Сегодня», «Задачи», «Дела», «Календарь», «Ещё»;
- полноценное досье дела: тип производства, доверитель, номер, суд/орган, судья/следователь,
  статья/квалификация, статус, мера пресечения, стадия, другая сторона, рабочая заметка;
- типы производств: уголовное, гражданское, КАС, КоАП, исполнительное, иное;
- специальные процессуальные сроки и калькулятор типовых сроков;
- быстрый «+»: заседание, процессуальный срок, задача и запись в журнал;
- глобальный поиск по делам, доверителям, номерам, судам, статьям, задачам и журналу;
- хронологический журнал внутри каждого дела;
- шаблоны чек-листов, включая уголовное дело, заседание, апелляцию, КАС, УДО, ст. 81 УК РФ;
- экспорт заседаний/сроков в файл `.ics` для системного Календаря iPhone;
- отчёт по делу и план дня;
- архив завершённых дел;
- напоминание о резервной копии.

## Учёт участия и гонорара

Почасовой учёт отсутствует. Любое фактическое участие адвоката считается как **1 день участия**,
независимо от продолжительности (5 минут или несколько часов). Ставка задаётся за день участия:
общая в профиле либо отдельная в конкретном деле. Для одного дела в одну дату приложение не создаёт
второй оплачиваемый день участия.

## Локальная защита

Рабочая база хранится локально в IndexedDB в зашифрованном виде (AES-GCM). По умолчанию используется
локальный ключ устройства. При включении 4-значного PIN база перешифровывается ключом, производным от PIN.
Сам PIN в базе не хранится.

Резервная копия также шифруется AES-GCM с отдельным паролем, который задаётся при создании файла.
Без этого пароля восстановить резервную копию невозможно.

Важно: это локальное веб-приложение, а не серверная система управления адвокатской тайной. Используйте
код-пароль/Face ID самого iPhone, не передавайте резервные файлы третьим лицам и храните их в защищённом месте.

## Установка на iPhone

1. Разместите все файлы из этой папки на HTTPS-адресе (например, GitHub Pages).
2. Откройте ссылку на iPhone.
3. В браузере выберите «На экран Домой». Если используемый браузер не предлагает корректную установку
   веб-приложения, откройте ту же ссылку в Safari.
4. Запустите приложение с появившейся иконки при включённом интернете хотя бы один раз.
5. Затем можно проверить запуск в авиарежиме.

Подробности — `INSTALL_IPHONE.txt`.

## Файлы

- `index.html` — оболочка интерфейса;
- `styles.css` — деловая тема;
- `app.js` — логика, шифрованное локальное хранилище и функции;
- `sw.js` — автономный кэш;
- `manifest.webmanifest` — параметры PWA;
- `icon-180.png`, `icon-192.png`, `icon-512.png` — иконки.
