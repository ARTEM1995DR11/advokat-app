# Ежедневник адвоката 5.0.116

## 5.0.116 — вкладка «Напоминания» доведена по утверждённому макету

- Шторка «Напоминания» снова собрана нативно из HTML/CSS, без подложенного скриншота.
- Верхний золотой медальон переведён на прозрачный круглый asset без квадратного фона.
- Декоративные золотые линии вокруг медальона собраны отдельным SVG-орнаментом.
- Иконки локальных уведомлений и системного календаря теперь рисуются нативно внутри кремовых карточек, без артефактов старых PNG-кропов.
- Убрана лишняя горизонтальная линия у иконки календаря.
- Карточки переразмерены по эталону: первая компактнее, вторая получила правильную высоту и ширину текстовой области.
- Нижняя золотая кнопка уменьшена и приведена к эталону по высоте, скруглению, шрифту, колокольчику и стрелке.
- Нижняя подпись, золотые линии, весы и «ДЕЛА В ПОРЯДКЕ» подняты и выровнены, чтобы полностью помещаться без прокрутки.
- ON/OFF меняет только состояние, текст и подпись кнопки; геометрия экрана остаётся неизменной.
- Пользовательская база и IndexedDB не изменялись.
