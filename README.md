## Версия 4.0.64

Доработка premium-списков:
- новая нижняя фирменная эмблема: весы в золотой медали;
- симметричный декоративный разделитель;
- оформление применяется ко всем premium-окнам выбора;
- build 4064 для обновления PWA-кэша.


Дополнительно в этой версии:
- В окне «Производство / кодекс» добавлены цветовые акценты по типу кодекса: ГПК/АПК — синий, КАС — зелёно-бирюзовый, УПК — красный, КоАП — янтарный.

- Исправлено: при выборе типа записи, приоритета и быстрых дат редактор сохраняет текущую позицию прокрутки и больше не прыгает наверх.
