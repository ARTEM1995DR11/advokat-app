Версия 3.1.73 — финальная доработка экрана «Задачи».

- добавлен отдельный фильтр по типу записи: Все типы / Задачи / Заседания / Встречи / Сроки;
- кнопка фильтра по типу выведена на сам экран «Задачи» рядом с поиском;
- завершённые заседания больше не смешиваются с обычным блоком «Выполнено»;
- для них создан отдельный раздел «История заседаний»;
- переходы с главной по заседаниям и срокам теперь открывают страницу «Задачи» сразу с нужным типом.
