# Ежедневник адвоката 5.0.96

## 5.0.96 — свайп судебных заседаний

- На странице «Задачи» запланированные судебные заседания теперь можно свайпать справа налево.
- Для будущего заседания открываются быстрые действия: «Изменить заседание», «Изменить дату», «Удалить».

- Нижняя навигационная панель этой версией не изменялась.
- Пользовательская база / IndexedDB этой правкой не изменяются.
- VERSION, CHANGELOG, README и Service Worker синхронизированы.

## Текущая версия: 5.0.96 — build 5096

Статическое PWA-приложение «Ежедневник адвоката» для iPhone/Android с офлайн-работой и установкой ярлыком на главный экран.

### Последние изменения
- Для iOS 26 нижняя панель больше не использует `fixed + bottom`, который может отрисовываться выше/ниже реальной границы viewport.
- Реальная нижняя граница берётся из `visualViewport`, после чего панель устанавливается через CSS-переменную `--ios-nav-top`.
- Пересчёт выполняется при первом запуске, `pageshow`, возврате из фона, изменении ориентации и `visualViewport`.
- `screen.height` и отрицательный `safe-area` для позиции навигации больше не используются.
- IndexedDB и пользовательские данные этой правкой не затрагиваются.
- README.md синхронизирован с версией 5.0.92.

### Актуальные основные ресурсы
- `quick-sheet-marble-approved.png` — фон окна «Быстрая запись».
- `nav-panel-light.png` и `nav-active-*.png` — нижняя навигация.
- `fab-plus-square-premium.png` — кнопка «+».
- `header-bell-premium.png` / `header-search-premium.png` — верхние action-кнопки.
- `bg-today-desk.png`, `bg-tasks-planner.png`, `bg-matters-folders.png`, `bg-cal-marble-calendar.png`, `bg-more-marble-office.png` — основные фоновые изображения разделов.

### Правило версионирования проекта
При каждом изменении создаётся новый архив версии. В одной версии синхронно обновляются номер версии/build, cache-busting ресурсов, Service Worker, CHANGELOG и README.
