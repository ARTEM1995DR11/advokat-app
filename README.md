## Версия 4.0.12

- Экран «Новое дело / Изменить досье» опущен ниже Dynamic Island на iPhone.
- «Быстрые действия» полностью переработаны в премиальный стиль приложения для светлой и тёмной тем.
- Добавлена контекстная иконка типа записи, аккуратные action-карточки и отдельный красный акцент удаления.

## Версия 4.0.11 — техническая ревизия

Проверена текущая сборка после переработки экранов «Сегодня», «Задачи», «Дела», «Календарь» и «Ещё».

Исправлено:
- синхронизированы номер версии, URL ресурсов и PWA-кэш; обновление теперь не требует удаления приложения с iPhone;
- отключено автоматическое удаление выполненных задач через 30 дней — очистка только вручную из настроек;
- добавлена дополнительная принудительная запись базы при уходе приложения в фон / закрытии страницы;
- удалён неиспользуемый тип «исполнительное производство» из внутренней логики карточек дел;
- тестовые HTML-файлы исключены из релизной сборки.

Данные продолжают храниться локально в IndexedDB в зашифрованном виде. Обновлять приложение нужно на том же домене/адресе, не удаляя PWA с экрана «Домой».
