# Ежедневник адвоката 3.1.100

Премиальная переработка шторок фильтров на страницах «Задачи» и «Дела».

- новый премиальный заголовок с иконкой;
- цветные иконки категорий;
- подчёркнутое выбранное значение;
- аккуратные счётчики;
- отдельные стили для светлой и тёмной тем;
- фильтр дел разделён на два визуальных блока: тип производства и основание ведения.
