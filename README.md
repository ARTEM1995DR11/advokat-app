# advokat-app 5.0.176

Сборка с доработкой премиального редактора записей.

Изменения:
- единый премиум-стиль для «Новая задача», «Новое заседание», «Новая встреча» и «Новый процессуальный срок»;
- одинаковые карточки выбора типа записи с подзаголовками и selected-state;
- фон колонн растянут на всю страницу, пелена уменьшена;
- унифицированы поля ввода, дата/время, выбор дела и кнопка сохранения.
