## Версия 4.0.55

- системные iOS-списки заменены на собственные premium-пикеры приложения;
- «Дело» открывается в фирменной шторке с поиском и данными дела;
- «Судья» открывается в отдельной шторке с поиском по ФИО и автоматической подстановкой суда;
- аналогичный интерфейс применяется к судам, стадиям, статусам и другим справочникам внутри форм;
- ручной ввод судьи/суда сохранён;
- поддержаны светлая и тёмная темы.
