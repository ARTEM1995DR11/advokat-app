# Ежедневник адвоката 3.1.95

Исправлена логика встреч:
- встреча никогда не считается просроченной;
- после наступления даты/времени она считается состоявшейся;
- состоявшиеся встречи переходят в историю и не считаются записями «в работе»;
- их можно открыть и при необходимости удалить либо перенести на другую дату;
- на странице «Сегодня» уже состоявшиеся встречи не остаются среди ожидающих событий.
