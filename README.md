# advokat-app 5.0.177

Исправление фонов после унификации премиального редактора.

- «Быстрая запись» снова использует только мраморный фон.
- В редакторах задачи, заседания, встречи и процессуального срока фон колонн растянут на всю страницу.
- Белая пелена ослаблена, чтобы колонны оставались видимыми и в нижней части формы.
