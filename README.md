# Ежедневник адвоката 4.0.96

## 4.0.96
- Полная матрица статусов доверителя: тип производства → стадия → допустимый статус.
- Уголовное: гражданский истец/ответчик убраны из основного статуса доверителя.
- Гражданское, КАС и КоАП получили отдельные списки статусов для каждой стадии.
- Несовместимый статус очищается при смене стадии.


## 4.0.89
- Длинный номер в списке «Дела» отображается как начало + многоточие + последние цифры, например `124012…504`.
- Убрано вторичное CSS-обрезание, из-за которого раньше могло получаться `124012……`.
- Короткие судебные номера остаются целиком.


Колокольчик уведомлений на пяти основных экранах вынесен в единый компонент и имеет одинаковое оформление.

# Ежедневник адвоката — 4.0.85

- Полные юридические формулировки статусов сохранены в окне выбора и в данных дела.
- В карточке/форме для стадии «Материал проверки» используются компактные подписи:
  - «Заявитель»;
  - «Проверяемое лицо»;
  - «Лицо, которому причинён вред»;
  - «Даёт объяснение».
- Это устраняет перенос длинных формулировок на 4–5 строк без потери юридической точности.
- Build 4085.


## 4.0.88
- Стадия «Материал проверки» визуально отделена от возбужденного уголовного дела: отдельная подпись, цвет и иконка на странице «Дела».


## 4.0.88
- Верхняя бренд-строка вынесена в единый компонент для пяти основных экранов.
- Колокольчик закреплён в одной геометрической точке: 42×42, right:0, top:1 внутри общей строки.
- Устранены различия положения между Сегодня / Задачи / Дела / Календарь / Ещё; у всех пяти экранов одинаковые боковые отступы 12 px.
