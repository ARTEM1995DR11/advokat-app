# Ежедневник адвоката 5.0.112

## 5.0.112 — единый экран «Напоминания» для включённого и выключенного состояния

- Исправлена ошибка, при которой внешний вид вкладки менялся целиком после включения или выключения уведомлений.
- Теперь используется один и тот же утверждённый визуал шторки.
- Динамически меняются только текст состояния, статусная плашка и подпись нижней кнопки.
- Фон, иконки, карточки, размеры и расположение элементов остаются неизменными.
- Build 5112.
