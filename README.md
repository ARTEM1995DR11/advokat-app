Версия 3.1.80 — первый этап переработки страницы «Дела» по утверждённому проекту.

Что изменено:
- стиль страницы «Дела» приведён к общей визуальной системе уже готовых экранов «Сегодня» и «Задачи»;
- переработаны карточки дел: номер, тип, статус, доверитель, суд, предмет, стадия и рабочие показатели получили чёткую иерархию;
- ближайшее заседание оформлено отдельной компактной плашкой;
- фильтры «Все / В работе / Архив / тип» сделаны компактнее;
- отдельно настроены светлая и тёмная темы в соответствии с утверждёнными макетами.

На этом этапе функциональная логика дел не менялась — только стиль и структура отображения.
