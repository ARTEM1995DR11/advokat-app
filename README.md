## Версия 4.0.68 — исправлено направление свайпов

Изменение относительно 4.0.67:

- Свайп слева направо открывает предыдущую основную вкладку.
- Свайп справа налево открывает следующую основную вкладку.
- Порядок вкладок сохранён: Сегодня → Задачи → Дела → Календарь → Ещё.
- Локальные свайпы карточек задач и прошедших заседаний по-прежнему имеют приоритет.
- Вертикальная прокрутка, формы, модальные окна и горизонтальные ленты не переключают страницы.
- Анимация перехода приведена в соответствие направлению навигации.
- Build 4068.

Основа: версия 4.0.67.
