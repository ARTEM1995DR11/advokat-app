Версия 3.1.72 — финальное усиление экрана «Сегодня».

- добавлен новый блок «Ближайшие 7 дней»;
- в него попадают ближайшие заседания, встречи и процессуальные сроки;
- обычные будущие задачи туда не выводятся, чтобы главная не засорялась;
- показываются только ближайшие записи, максимум 5;
- справа добавлена кнопка «Все →» с переходом в календарь.
