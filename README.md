# Версия 4.0.75 — чистые поля выбора и статус доверителя

- Убраны лишние пустые пункты «выбрать суд / орган» и подсказки внутри соответствующих полей редактора дела.
- Стадия по-прежнему выбирается только из фактических стадий, без отдельной строки «выбрать стадию».
- «Процессуальный статус» переработан в «Статус доверителя»: это только процессуальное положение самого доверителя, а не роль адвоката.
- Удалены варианты «представитель» и «защитник».
- Набор статусов автоматически зависит от типа производства: уголовное / гражданское / КАС / КоАП / иное.
- Статус теперь выбирается только из допустимого списка, свободный ввод отключён.
- Старые значения «осужденный» и прежний статус КоАП автоматически нормализуются; старые адвокатские роли очищаются.
- Сохранены premium-оформление, зависимая логика стадии/органа и исправленная маска телефона.
- Build 4075.
