## Версия 4.0.33

Точечная доработка для тёмной темы после внедрения новых фоновых изображений экранов.

Что изменено:
- фон в тёмной теме стал визуально спокойнее и не мешает чтению;
- шапка экранов (название приложения, заголовок страницы, подпись) стала контрастнее;
- поисковая кнопка и верхние элементы лучше отделяются от фонового изображения;
- светлая тема сохранена без изменений;
- build обновлён до 4033.
