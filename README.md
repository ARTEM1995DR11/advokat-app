# Версия 4.0.80 — статусы доверителя по стадии уголовного дела

- Для уголовных дел список «Статус доверителя» теперь зависит от выбранной стадии.
- На стадии «Материал проверки» оставлены только реальные для доследственной проверки варианты: заявитель; лицо, в отношении которого проводится проверка; пострадавший (до признания потерпевшим); лицо, дающее объяснение.
- Для дознания и предварительного следствия показываются только статусы этой стадии; для суда, обжалования и исполнения — свои списки.
- При смене стадии несовместимый старый статус автоматически очищается, чтобы карточка не содержала противоречивые данные.
- В окне выбора статуса показывается текущая стадия уголовного дела.
- Build 4080.
