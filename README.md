# Ежедневник адвоката 4.0.4

Первая сборка новой основной линейки 4.x.

Версия 4.0.3 фиксирует крупное обновление приложения:
- единый премиальный интерфейс в светлой и тёмной темах;
- переработанные экраны «Сегодня», «Задачи», «Дела», «Календарь» и «Ещё»;
- отдельные типы задач, встреч, заседаний и процессуальных сроков;
- новая система карточек и фильтров дел;
- поддержка «По соглашению» / «По назначению»;
- обновлённые формы создания и редактирования записей и дел.


Дополнительно в 4.0.3:
- компактные карточки дел получили разные иконки по категориям;
- подписи номера дела и доверителя сделаны контрастнее;
- для административных дел сокращён заголовок категории до «Иск КАС», чтобы он помещался в одну строку.


Версия 4.0.4:
- на странице «Ещё / Настройки» убрана плавающая кнопка «+»;
- при новом запуске приложение всегда открывается на странице «Сегодня»;
- после возврата в приложение из фона рабочий экран также возвращается на «Сегодня».
