## Версия 4.0.70 — единый колокольчик уведомлений

- На всех основных страницах — «Сегодня», «Задачи», «Дела», «Календарь», «Ещё» — используется один и тот же колокольчик уведомлений.
- Размер, форма, фон, рамка, тень, положение и SVG-иконка полностью едины.
- На «Дела», «Календарь» и «Ещё» поиск перенесён к заголовку страницы, как на «Сегодня» и «Задачи».
- Светлая и тёмная темы поддерживаются.
- Build 4070.

## Версия 4.0.69 — поиск «Задачи» как на «Сегодня»

- Кнопка поиска на экране «Задачи» перенесена из верхней бренд-строки в строку заголовка.
- Положение, размер, радиус, прозрачность, тень и иконка повторяют кнопку поиска на экране «Сегодня».
- Функция поиска по задачам сохранена без изменений.
- Светлая и тёмная темы поддерживаются.
- Build 4069.
