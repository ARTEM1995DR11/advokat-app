# Ежедневник адвоката 5.0.141

Сборка 5.0.141 / build 5143.

Изменение этой версии:
- «Быстрая запись»: возвращён выраженный глянцевый стеклянный стиль иконок.
- Иконки остаются живыми SVG без вшитых декоративных линий.
- Золотые декоративные дуги карточек остаются отдельным слоем позади иконки, поэтому больше не должны пересекаться с графикой самой стекляшки.
- «Глобальный поиск» в этой версии не изменялся.
