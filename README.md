# Ежедневник адвоката

Текущая версия: **5.0.364**

Мобильное offline-first приложение «Ежедневник адвоката».

## Публикация

Содержимое этой папки предназначено для публикации в корень репозитория GitHub Pages.

Основные файлы:
- `index.html`
- `app.js`
- `styles.css`
- `sw.js`
- `manifest.webmanifest`

Остальные изображения и WebP-файлы являются используемыми локальными ресурсами приложения.

## Важно

Рабочие данные пользователя хранятся локально в браузере/на устройстве. Обновление файлов приложения в том же GitHub Pages-адресе не должно требовать повторного создания дел и задач.
