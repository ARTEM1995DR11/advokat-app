## Версия 4.0.73 — стадии дела и зависимый суд / орган расследования

- Для уголовных дел вместо общей стадии «Досудебная работа» добавлены: «Материал проверки», «Дознание», «Следствие МВД», «Следствие СК».
- Стадия теперь выбирается из premium-списка без пустого пункта «выбрать стадию» и имеет собственную цветовую гамму.
- Поле места производства зависит от стадии: судебные стадии показывают «Суд», досудебные уголовные — «Орган расследования», исполнение — «Орган исполнения».
- Для досудебных стадий добавлены: ОД МО МВД РФ Кинешемский, СО МО МВД РФ Кинешемский, СО по г. Кинешма СУ СК РФ, Кинешемский РОСП.
- На стадии «Дознание» доступны ОД МО МВД РФ Кинешемский и Кинешемский РОСП; для следствия МВД и СК список автоматически фильтруется.
- В судебной стадии показывается поле судьи; в досудебной уголовной стадии — следователь или дознаватель.
- Старые уголовные стадии автоматически приводятся к новой структуре при загрузке базы.
