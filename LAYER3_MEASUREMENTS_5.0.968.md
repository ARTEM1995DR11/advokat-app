# Слой 3. Измерение макета и установка — 5.0.968 / build 5968

## Область и точность измерений

Исходный эталон: предоставленный пользователем растровый крупный план карточки, 1536 × 576 пикселей. Слой 3 закрыт частично слоями 2 и 4, поэтому реально видимые кромки можно измерить по растру, а геометрию скрытых участков можно лишь реконструировать. Ниже приводятся измеренные **оптические ориентиры**, а не исходные координаты недоступного многослойного PSD/Figma-макета.

Поскольку эталон 1536 × 576 — крупный план, а приложение рендерится в 402 CSS px, координаты калиброваны по наружным краям папки: в эталоне область x≈60…1470, в приложении x≈16…390 CSS px. Приближённый переход: x(CSS) ≈ 16 + (x(mock)-60) × 374/1410. Погрешность ориентиров по видимым линиям: ±2–4 CSS px после ресайза, на тенях выше.

### Алгоритм изготовления (порядок соблюдён)
1. Измерены видимые линии на исходном макете в его 1536×576 пикселях; отдельно сохранено увеличенное изображение с координатной сеткой.
2. Под эти ориентиры самостоятельно построен **самостоятельный SVG** с прозрачным фоном и четырьмя разнесёнными бумажными кромками. Слой 3 не включает детали кожаной вкладки, крафта, лицевой панели, скрепку и тексты.
3. SVG отрисован отдельно; подтверждены размер и ненулевые пиксели только в центрально-правом диапазоне (примерно x=196…357).
4. Готовый SVG установлен отдельным `<img>` на текущую страницу карточки вместо слоя 3 из 5.0.967. После пробных сопоставлений с лицевой панелью сохранено штатное положение третьего слоя `top: 15px`: сдвиг до `12px` открывал слишком много белой бумаги. Сохранён порядок 1 → 2 → 3 → 4.
5. Выполнена реальная проверка в Chromium на базе HTML/CSS/JS приложения при ширине viewport 402 CSS px и DPR2 по всем четырём видам производства, без загрузочных ошибок изображений.

## Проверка неизменности

Слои 1, 2, 4, их изображения, размеры, преобразования, live-текст, статус, скрепка, шапка, фон страницы, навигация не редактировались. Из графики изменена только самостоятельная форма слоя 3. Значения позиционирования в CSS сохранены.

## Остаточная неопределённость

Буквальная пиксельная идентичность на всём контуре не может быть доказана по сплющенному JPG с отличной от устройства перспективой и закрытыми участками. Проверено соответствие **видимого силуэта**, отсутствие прежнего длинного белого выступа и корректность наложения в эмуляции. Финальная оптическая приёмка остаётся за скриншотом установленной сборки на iPhone.
