Ежедневник адвоката — 5.0.1297.41.66.70 (сборка 6510)
Обновление относительно версии .69

- Исправлена причина обрезания плашки статуса «Включены»: статус вынесен из контейнера описания в самостоятельную строку адаптивной сетки первой карточки. Сетка задаёт высоту карточки по содержимому, а не по прежней геометрии текста.
- Для первой карточки локально сброшены старые ограничения высоты и позиционирования. Плашка остаётся внутри золотой рамки с нижним отступом и не перекрывает следующую карточку.
- Для всех состояний (включено, выключено, запрещено, недоступно) используется одна и та же двухрядная раскладка; вторая карточка и остальная страница не менялись.
- Сохранены золотые иконки из версии .68, фон, основной текст, обработчики напоминаний и кнопка переключения.
- Исправлены ошибочные имена SVG-ресурсов в обязательном списке Service Worker: теперь указаны существующие v6508, включённые в пакет. Это предотвращает срыв установки из-за отсутствующих v6509/v6510 SVG.
- Обновлены номера версии 5.0.1297.41.66.70, build 6510 и кэш PWA.

УСТАНОВКА: компактное обновление поверх версии 5.0.1297.41.66.69, распаковать в корень репозитория с заменой файлов. Обе существующие SVG-иконки включены повторно для надёжности; их внешний вид не изменён.
