Техническая стабилизация запуска PWA и загрузки изображений для iPhone.

1. Service Worker ищет PNG/WebP/SVG по имени и пути, игнорируя устаревший параметр ?v= только для графики. JS, HTML и CSS остаются строго привязаны к своей сборке.

5. Изображения папки предварительно загружаются без принудительного декодирования больших картинок в память при старте приложения.
6. Сохранены все элементы утверждённого дизайна и функции версии 5.0.1297.41.66.19. Локальные данные, настройки и PIN не очищаются.
