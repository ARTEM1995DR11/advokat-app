5.0.818 / build 5818 — ЭТАП «ПОЗИЦИЯ ПО ДЕЛУ»

- В открытой карточке дела добавлена секция «Позиция по делу».
- Для пустой позиции отображается реальная команда «Сформировать позицию».
- При заполнении появляется краткое содержание и команда «Редактировать позицию».
- Пять структурированных полей: цель, аргументы, доказательства, риски, план.
- В форме «Новое дело / Изменить дело» есть сворачиваемый необязательный раздел позиции.
- Все поля живут внутри записи S.matters[].position и сохраняются в том же шифрованном хранилище.
- Изменение позиции регистрируется отдельным системным событием в журнале; системные записи защищены от удаления.
- Архивная карточка позволяет прочесть все поля позиции без кнопки редактирования.
- В учебных делах добавлены заполненные примеры позиции, один учебный кейс оставлен пустым для проверки кнопки.
- Версия, build, имена кэша Service Worker и cache-busting обновлены.

ВАЖНО: этот шаг добавляет функциональную возможность позиции без полной визуальной переработки карточки по четырём утверждённым макетам.
Дизайн страницы «Дела» и её CSS, поиск/фильтры и нижняя панель не изменялись.
Перед установкой рекомендуется создать резервную копию данных средствами приложения.
