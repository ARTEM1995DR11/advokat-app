5.0.926 / build 5926 — оптимизация запуска PWA без изменения дизайна и данных.

- Иконки папок уменьшены для Retina iPhone с сохранением исходников в архиве (статические WebP 384x384), загрузка невидимых иконок отложена; изображения визуально те же.
- Убрана повторная перерисовка приложения при первичном событии pageshow, восстановление из BFCache остаётся.
- Сняты неиспользуемые preloads модальных окон/форм с критического пути запуска.
- Service Worker теперь устанавливает приоритетные ресурсы сразу, а тяжёлые второстепенные ресурсы прогревает в фоне. При работе офлайн после первого обновления дождитесь завершения фоновой загрузки; данные IndexedDB не изменяются.
- Нормализованы ссылки на ресурсы до build 5926, чтобы избежать двойной загрузки между CSS/HTML/SW.
- Заявленные утверждённые размеры, расположение, палитра, шрифты и логика карточек не изменены.
