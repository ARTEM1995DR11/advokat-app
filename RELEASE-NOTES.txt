5.0.822 / build 5822 — КАРТОЧКА ДЕЛА: ВРЕМЕННО ПУСТОЙ МАКЕТ

• В карточке временно включён изолированный режим работы только над дизайном.
• Убраны из отображения личные сведения, реквизиты, события, задачи, журнал и счётчики.
• Сохранены фон, корпус папки, цветная верхушка по типу производства, скрепка, четыре вкладки и три пустых бумажных листа.
• Все реальные данные остаются в действующем хранилище и других разделах без изменений; существующий подробный вывод карточки сохранён в коде для восстановления по завершении дизайна.
• Ни один утверждённый файл страницы «Дела» не изменён.

5.0.822 / build 5822 — ПРЕМИАЛЬНАЯ КАРТОЧКА ДЕЛА — ПЕРВЫЙ ВИЗУАЛЬНЫЙ ЭТАП

• Вкладка «Общее»: новая шапка досье, физические бумажные вкладки, ближайшее событие, основная информация, три последние записи журнала.
• Вкладки «Общее», «События», «Задачи», «Журнал» переключают отображаемые разделы, все связанные данные поступают из S.tasks и S.journal.
• Заголовок — доверитель / подзащитный, под ним предмет, вид, номер, стадия и статус.
• Убраны с главного экрана «Позиция по делу» и любые заменяющие аналитические блоки.
• В форме «Новое дело» исключены дополнительные поля позиции; сохранённые в предыдущих версиях данные намеренно НЕ удаляются.
• Стили страницы «Дела», папок, поиска и фильтров остаются побайтово прежними.
• Переработка карточки будет продолжена; текущая версия — первая кодовая итерация, не окончательная пиксельная шлифовка.
