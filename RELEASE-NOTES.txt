5.0.1297.41.66.20 — сборка 6460

Техническая стабилизация запуска PWA и загрузки изображений для iPhone.

1. Service Worker ищет PNG/WebP/SVG по имени и пути, игнорируя устаревший параметр ?v= только для графики. JS, HTML и CSS остаются строго привязаны к своей сборке.
2. Старый офлайн-кэш сохраняется до успешного переноса всех дополнительных изображений. Изображения доступны из предыдущего кэша при обновлении без сети.
3. Основные ресурсы нового выпуска кешируются с ограничением параллельности (3), чтобы не перегружать iOS при установке обновления.
4. При сетевых ошибках, HTTP 5xx или долгом ответе при открытии приложения используется сохранённая исправная HTML-оболочка.
5. Изображения папки предварительно загружаются без принудительного декодирования больших картинок в память при старте приложения.
6. Сохранены все элементы утверждённого дизайна и функции версии 5.0.1297.41.66.19. Локальные данные, настройки и PIN не очищаются.

ВАЖНО: системная ошибка Safari «На странице повторно возникла проблема» может быть связана также с нехваткой памяти WebKit; корректный кэш снижает риски, но не гарантирует устранение всех причин без диагностики устройства.
