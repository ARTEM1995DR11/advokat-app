5.0.1197 / build 6197 — единое вертикальное выравнивание нижних кнопок четырёх вкладок карточки дела.
— Вкладки «Общее», «События», «Задачи», «Журнал»: начало общего SVG-контейнера кнопок теперь привязано к нижней кромке последнего бумажного блока, отступ −2 CSS px.
— Привязка пересчитывается после появления содержимого, смены вкладок, обновления журнала и изменения ширины экрана. ResizeObserver следит за высотой последнего листа.
— Бумажная форма, иллюстрация нижней золотой кромки, тексты, иконки, размеры и действия кнопок не изменялись.
— Для длинного списка, нуля записей и нескольких записей действует один алгоритм; фиксированные отступы прошлых сборок больше не определяют видимое положение.
— Версия, cache-busting HTML, JS и Service Worker синхронизированы с 6197.
