ЕЖЕДНЕВНИК АДВОКАТА — IPHONE OFFLINE 3.2

1. Распакуйте ZIP на компьютере.
2. На GitHub создайте репозиторий, например advokat-app.
3. Загрузите В САМ КОРЕНЬ репозитория все файлы из распакованной папки. Файл index.html должен быть
   виден сразу в корне, а не внутри ещё одной вложенной папки.
4. GitHub → Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
5. После публикации откройте HTTPS-ссылку приложения на iPhone.
6. Используйте «Поделиться» / меню браузера → «На экран Домой». Если Яндекс Браузер на вашей версии iOS
   корректно предлагает этот пункт и открытие как веб-приложения, можно установить из него. При проблемах
   откройте ту же ссылку в Safari и добавьте на экран Домой там.
7. Первый запуск с иконки выполните при включённом интернете. Дождитесь полной отрисовки главного экрана.
8. Закройте приложение, включите авиарежим и снова запустите с иконки — интерфейс должен открыться офлайн.

БЕЗОПАСНОСТЬ

• На GitHub лежит только код приложения. Доверители, дела, задачи и журнал сохраняются локально на iPhone.
• В разделе «Ещё → Код доступа и шифрование» можно включить PIN-шифрование.
• В разделе «Ещё → Зашифрованная резервная копия» регулярно сохраняйте копию с отдельным паролем.
• Не забывайте пароль резервной копии: приложение его не хранит.
• Критичные заседания и процессуальные сроки рекомендуется дополнительно выгружать в системный Календарь
  iPhone кнопкой «Добавить в календарь iPhone», поскольку iOS может приостанавливать PWA в фоне.

УЧЁТ УЧАСТИЯ

В приложении нет почасового тарифа. Фактическое участие адвоката учитывается по дням: одно участие по делу
в конкретную дату = один день участия независимо от продолжительности.
