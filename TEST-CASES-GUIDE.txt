ТЕСТОВЫЙ СЦЕНАРИЙ 5.0.816

1. Дела → Фильтры → Тестовые дела → Загрузить 7 вымышленных дел.
2. По умолчанию показываются 4 дела в производстве. У каждого есть полные реквизиты, история и связанные записи.
3. Откройте любое дело → «Ещё действия» → «Завершить дело». Укажите дату, исход, описание и подтвердите незавершённые задачи, если они имеются. Дело переместится в архив.
4. Дела → Фильтры → Архив: открываются 3 уже завершённых учебных дела и все вновь завершённые. Откройте карточку: дата, результат и итог сохранены.
5. В архивном деле → «Вернуть в работу»: дело вернётся в активные, запись о завершении останется в журнале.
6. Дела → Фильтры → Тестовые дела → Удалить только учебные дела. Настоящие дела и их записи не удаляются.

ВАЖНО: Все имена, номера, органы и события в учебном наборе вымышлены. Набор не загружается автоматически в существующую базу.
За действующее дело решение о закрытии принимает адвокат: судебное заседание, прекращение проверки или вынесение решения сами по себе дело не закрывают.
«Архивировать без завершения» — самостоятельное действие для временно неактуального дела, не равное отметке «Завершено».
